# GreenOps - Energy Management Platform

## 📋 Project Description

GreenOps is an advanced energy management platform designed to help businesses monitor, analyze, and optimize energy consumption across multiple retail locations. The platform provides real-time insights, predictive analytics, and actionable recommendations to reduce energy costs and improve sustainability.

## ✨ Features

- **Real-time Energy Monitoring** - Track energy consumption across all locations in real-time
- **Advanced Analytics Dashboard** - Visualize energy usage patterns with interactive charts and graphs
- **Predictive Analytics** - Machine learning-powered forecasts for future energy consumption
- **Multi-location Management** - Manage and compare energy usage across different retail locations
- **Cost Optimization** - Identify opportunities to reduce energy costs and improve efficiency
- **Sustainability Reporting** - Generate comprehensive reports for ESG compliance
- **Alert System** - Receive notifications for unusual consumption patterns or anomalies
- **Responsive Design** - Fully responsive interface that works seamlessly on desktop and mobile devices

## 🚀 Installation & Setup

### Prerequisites

- Node.js (v18 or higher)
- npm or bun package manager

### Local Development

1. Clone the repository:
```bash
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
```

2. Install dependencies:
```bash
npm install
# or
bun install
```

3. Start the development server:
```bash
npm run dev
# or
bun run dev
```

4. Open your browser and navigate to `http://localhost:8080`

## 📖 Usage Guide

### Getting Started

1. **Dashboard Overview** - Upon loading the application, you'll see the main dashboard with energy consumption metrics
2. **Location Selection** - Use the location selector to filter data for specific retail locations
3. **Time Range Selection** - Adjust the time range to view historical data and trends
4. **Analytics** - Explore detailed analytics and predictions in the analytics section
5. **Export Reports** - Generate and download energy consumption reports for your records

### Key Navigation

- **Home** - Main dashboard with overview metrics
- **Analytics** - Detailed energy consumption analysis
- **Locations** - Manage and compare different retail locations
- **Reports** - Generate and download comprehensive reports
- **Settings** - Configure platform preferences and notifications

## 🎨 Technology Stack

### Frontend
- **React 18** - Modern UI library for building interactive interfaces
- **TypeScript** - Type-safe JavaScript for better developer experience
- **Vite** - Fast build tool and development server
- **Tailwind CSS** - Utility-first CSS framework for responsive design
- **shadcn/ui** - High-quality, accessible UI components
- **Recharts** - Powerful charting library for data visualization
